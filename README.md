# dominigames.ru

Сайт ООО «ДОМИНИГЕЙМС»: главная страница и юридическая информация (аккредитация в Минцифре, политика конфиденциальности, условия использования).

Сайт статический — обычные HTML-файлы без сборки. Каждый push в ветку `main` запускает на GitHub сборку, которая публикует сайт через GitHub Pages на домен из файла `CNAME`. Статус сборок: [Actions](https://github.com/dominigamesru/website/actions).

## Что где лежит

| Страница | Адрес | Файл |
|---|---|---|
| Главная | https://dominigames.ru/ | `index.html` |
| Аккредитация (реквизиты, ОКВЭД, коды ИТ-деятельности, услуги) | https://dominigames.ru/accreditation/ | `accreditation/index.html` |
| Политика конфиденциальности | https://dominigames.ru/privacy-policy/ | `privacy-policy/index.html` |
| Условия использования | https://dominigames.ru/terms/ | `terms/index.html` |
| Логотип, фавикон, иконки игр | — | `images/` |

Стили каждой страницы лежат прямо в ней, в теге `<style>`. Общих CSS/JS-файлов нет.

## Главное правило

**Текст на страницах — юридический.** Он публикуется ровно так, как его прислали юрист или бухгалтерия, со всеми запятыми, тире и даже опечатками. Менять можно только оформление (вёрстку). Если в тексте есть ошибка, сообщите об этом автору текста, а не исправляйте сами.

## Как обновить сайт

### Вариант 1. Через Claude Code (проще всего)

1. Откройте папку репозитория в VS Code с Claude Code.
2. Вставьте присланный текст целиком и напишите, куда его добавить. Например: «Добавь на страницу аккредитации в раздел 1 строку…».
3. Claude сам использует скилл `updating-site-content`: внесёт текст без изменений, проверит, что существующий текст не пострадал, и перечислит вопросы (опечатки, противоречия, дата редакции).
4. Напишите «покажи сайт», чтобы посмотреть результат (скилл `previewing-site`, см. «Просмотр локально»). Если всё верно, попросите Claude сделать коммит и push.
5. Через 1–2 минуты проверьте на [странице сборок](https://github.com/dominigamesru/website/actions), что появилась зелёная галочка: это значит, что сайт обновлён (подробнее — в шаге 5 варианта 2).

### Вариант 2. Вручную

1. `git pull`
2. Отредактируйте нужный `index.html`. Для новых элементов используйте существующие классы: строка таблицы реквизитов — `<tr><td>Метка</td><td>Значение</td></tr>` внутри `.main__table`.
3. Проверьте, что поменялся только нужный текст:
   ```bash
   python .claude/skills/updating-site-content/text_diff.py
   ```
   Скрипт показывает изменения только в видимом тексте: `+` — добавлено, `-` — удалено или изменено. Если меняли только вёрстку, он должен написать `no text changes`.
4. Посмотрите страницу в браузере на компьютере и в узком окне (мобильный вид).
5. Закоммитьте с понятным сообщением на русском и отправьте:
   ```bash
   git add -A
   git commit -m "аккредитация: добавлены коды ИТ-деятельности 12.01 и 22.01"
   git push
   ```
   После push GitHub сам запускает сборку и публикацию (GitHub Pages), обычно за 1–2 минуты. Ход сборки: https://github.com/dominigamesru/website/actions
   - жёлтый кружок — сборка идёт;
   - зелёная галочка — сайт обновлён, откройте https://dominigames.ru/ и нажмите Ctrl+F5;
   - красный крестик — ошибка, сайт остался в прежнем виде. Откройте сборку, чтобы увидеть причину, или попросите Claude разобраться.

## Просмотр локально

Через Claude Code достаточно написать «покажи сайт». Claude запустит просмотр, откроет страницу в браузере и объяснит, что делать дальше (скилл `previewing-site`). Чтобы выключить просмотр, напишите «останови превью».

Вручную:

```bash
python -m http.server 8000
```

Откройте http://localhost:8000/. Если открыть файл двойным кликом, ссылки между страницами работать не будут.

## Скиллы Claude Code

Скиллы лежат в `.claude/skills/`. Вызывать их вручную не нужно: достаточно написать Claude обычными словами, и он сам выберет подходящий.

| Скилл | Что делает | Что написать Claude |
|---|---|---|
| `updating-site-content` | Вносит присланный текст без изменений, улучшает вёрстку, проверяет, что существующий текст не пострадал, и задаёт вопросы по опечаткам и противоречиям | «Добавь на страницу аккредитации…», «Обнови политику конфиденциальности…» |
| `previewing-site` | Запускает просмотр сайта на вашем компьютере, открывает нужную страницу в браузере и выключает просмотр по просьбе. Команды вводить не нужно | «Покажи сайт», «Покажите, как будет выглядеть политика», «Останови превью» |

Во время просмотра:
- изменения видны только на вашем компьютере, настоящий сайт не меняется;
- после новых правок нажмите **F5**;
- мобильный вид: **F12**, затем **Ctrl+Shift+M** и выберите телефон сверху.

## Что учесть

- **Реквизиты повторяются** на нескольких страницах: аккредитация, политика конфиденциальности и подвал главной. При смене ИНН, адреса, телефона или почты найдите все вхождения (поиск по старому значению) и обновите везде.
- **Дата редакции** («Редакция от …») в политике и условиях меняется только по решению юриста.
- **Год в подвале** (`© Доминигеймс, 2020 – 2026`) есть на каждой странице.
- **Новая игра в карусели на главной:** положите иконку в `images/games/` и добавьте `<img>` в оба блока `carousel__track` (второй блок — копия для бесконечной прокрутки).
